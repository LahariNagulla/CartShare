# CartShare 🛒

CartShare is a collaborative shopping web application that allows multiple users to create or join a shared shopping room and manage a common shopping cart.

## Features

- Create a shopping room
- Join an existing room using a room code
- Add shopping items
- Set quantity and price
- Quick-add popular items
- View shared cart items
- Remove items from the cart
- Calculate estimated total
- Real-time synchronization between browser tabs
- Activity log
- Printable shopping receipt
- Responsive design for desktop and mobile

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using a browser.
4. For the best experience, use the VS Code Live Server extension.

## How It Works

1. Create a room or join an existing room.
2. Enter your name and room code.
3. Add items to the shared shopping cart.
4. Set the quantity and price for each item.
5. View the estimated total.
6. Use the activity log to track changes.
7. Use the Print Receipt option to generate a printable copy.

## Browser Tab Synchronization

CartShare uses browser `localStorage` and the JavaScript `storage` event to synchronize cart and activity updates between browser tabs using the same room code.

## Project Purpose

CartShare was developed as a collaborative shopping application where multiple users can manage a shared shopping list within a common room.
